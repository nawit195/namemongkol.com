## การรักษาข้อมูล

- สำรองทุกคอลัมน์ก่อนเขียน และใช้ transaction พร้อม snapshot guards ตรวจข้อมูลก่อนแก้แต่ละชุด
- รักษา id, วันสร้าง, เพศ และสถานะการตรวจของชื่อเดิม เติมเฉพาะช่องว่างที่ไม่ขัดกับการตรวจหรือ draft เดิม
- รักษาข้อมูลเดิมที่ต่างจากไฟล์ 129 ช่องในพรีเมียม และ 509 ช่องในฐานสาธารณะ ไม่เลือกข้อความใหม่มาทับอัตโนมัติ
- ชื่ออังกฤษ `ธรรม์` ในไฟล์มีสองตัวเลือก `Than / Tham` จึงเว้นเฉพาะฟิลด์อังกฤษจากแหล่งนี้และบันทึกไว้ใน `invalidFields` โดยไม่เลือกตัวสะกดแทนผู้ใช้ รายชื่อไม่ได้ถูกตัดออก
- คำอ่านและความหมายใหม่ยังใช้สถานะ `pending` ตาม schema ไม่ยกระดับเป็นข้อมูลภาษาที่ผ่านการตรวจโดยอัตโนมัติ
- คะแนน เกรด คู่เลข และวันเกิดยังคำนวณด้วยสูตรเว็บไซต์ ไม่ใช้ค่าประกอบจาก Excel ทับสูตร ไม่แตะเครดิตหรือประวัติผลวิเคราะห์

## การตรวจรับ

- ตรวจข้อมูลก่อนนำเข้าครบ 7,050 แถวพรีเมียมและ 14,270 แถวสาธารณะ เทียบทุก before-value กับ patch หลังเขียนจริง
- ตรวจชื่อ A+ ครบ 156 ชื่อ และ A-B ครบ 433 ชื่อในฐานจริง รันแผนนำเข้าซ้ำได้ 0 changes ทั้งสองชุด
- PostgreSQL จำลองผ่านทั้งสอง importer: bigint/UUID defaults, สถานะตรวจเดิม, การรันซ้ำ, snapshot เปลี่ยนแล้ว rollback และข้อความที่มี quotes/dollar delimiters
- Vitest ที่เกี่ยวกับ importer/catalog/details/English ผ่าน 5 files / 18 tests และตรวจ syntax/ESLint ของ verifier
- Vercel invalidate เฉพาะแท็ก `premium-names`, `public-names`, `public-stats`, `public-live-stats` สำเร็จ แคชแบบ stale-while-revalidate อาจตอบชุดเก่าหนึ่งรอบระหว่างอัปเดต
- API พรีเมียมจริงตอบ 200, total 7,086 และพบชื่อจากชีตครบ 156 ชื่อ ทั้งสองหน้าพรีเมียมตอบ 200 ตัวนับโหลดผ่าน API จึงไม่ใช้การค้นหาตัวเลขใน HTML เริ่มต้นเป็นหลักฐานยืนยันตัวนับ
- `/search` จริงตอบ 200 แสดง 14,424 ชื่อ และมีชื่อใหม่อยู่ใน HTML เริ่มต้น ตรวจรายชื่อ A-B ใหม่ทั้ง 124 ชื่อผ่าน API ตามอักษรนำของหน้าเว็บ

ระบบอนุมัติอัตโนมัติปฏิเสธคำสั่ง purge Data Cache ทั้งโครงการ เพราะขอบเขตกว้างและอาจกระทบแคชอื่น จึงไม่ได้รันคำสั่งนั้น ใช้การ invalidate รายชื่อเฉพาะแท็กและตรวจผลอ่านจริงแทนจนข้อมูลอัปเดต

## ไฟล์ตรวจสอบและการปรับเครื่องมือ

Snapshot, แผนนำเข้า, SQL transaction และผลตรวจอยู่ใน `scratch/premium-aplus-import/2026-11-25-filled/` และ `scratch/filtered-names-import/2026-11-25-filled/` ซึ่งถูก gitignore ไม่เพิ่มข้อมูลรายชื่อดิบจากไฟล์นี้เข้า Git

ปรับ extractor ให้คำนวณขอบเขตชีตเมื่อไฟล์ streaming XLSX ไม่ระบุ dimensions และให้ตรวจรูปแบบอังกฤษตรงกับ importer ปรับ verifier A-B ให้รับ manifest/directory ของแต่ละรอบโดยยังรักษาค่า default เดิม ไม่ต้องเปลี่ยน UI หรือ deploy เพื่อให้รายชื่อชุดนี้ใช้งานได้
