# ตรวจ SEO หน้ารวมและหน้าวอลเปเปอร์วันเกิด

วันที่ 20 พฤศจิกายน 2569 ตรวจ `/wallpapers`, Saturday, Sunday และ Thursday จาก source, ภาพ WebP จริง, metadata ที่ render และตัวอย่างผลค้นหาภาษาไทย

## สิ่งที่พบและแก้ไข

- หน้าวันเกิดใช้ Title ที่มีชื่อแบรนด์แล้ว แต่ยังผ่าน title template ของ layout จึงมีโอกาสเป็น `NameMongkol | NameMongkol` เปลี่ยนเป็น absolute title และใช้ข้อความตรงกันใน Open Graph/Twitter
- หน้าวันเกิดมี H1 แบบซ่อนพร้อม H1 หน้ารวมจาก ClientPage เปลี่ยนเป็น H1 ประจำวันที่มองเห็นได้จากเซิร์ฟเวอร์ และให้ ClientPage แสดงเฉพาะส่วนเลือกภาพ
- บทนำและ FAQ เดิมเหมือนกันทุกวัน เปลี่ยนสามหน้าที่ตรวจให้มีภาพประจำวัน ความหมาย กลุ่มผู้ใช้ และวิธีจัดตำแหน่งหน้าจอเฉพาะภาพ
- คำอธิบายวันพฤหัสบดีเดิมระบุปางสมาธิไม่ตรงรายละเอียดพระหัตถ์ในภาพ ใช้คำบรรยายองค์ประกอบที่ตรวจเห็นจริง โดยไม่ระบุปางที่ยังไม่ยืนยัน
- Alt เดิมต่อชื่อ วันเกิด คำเสริมดวง แท็ก และแบรนด์เข้าด้วยกัน เปลี่ยนสามภาพเป็นคำบรรยายภาพจริง และให้ภาพอื่นใช้ชื่อภาพโดยไม่เติมแท็กซ้ำ
- เพิ่มลิงก์ HTML จากหน้ารวมไป Sunday และ Thursday ซึ่งเดิมมีเฉพาะบางวัน

## Keyword ownership และ Search Intent

| หน้า | Intent | Title ใหม่ |
| --- | --- | --- |
| `/wallpapers` | เลือกดูภาพตามวันเกิด/ราศีและคอลเลกชัน เปรียบเทียบเงื่อนไขดาวน์โหลด | วอลเปเปอร์มงคลตามวันเกิดและราศี \| NameMongkol |
| `/wallpapers/day/saturday` | คนเกิดวันเสาร์หาภาพมือถือ โทนม่วงทอง พระนาคปรกและเลข 156 | วอลเปเปอร์วันเสาร์ พระนาคปรก เลข 156 \| NameMongkol |
| `/wallpapers/day/sunday` | คนเกิดวันอาทิตย์หาภาพมือถือ โทนแดงทอง สิงห์ทองและเลข 159 | วอลเปเปอร์วันอาทิตย์ สิงห์ทอง เลข 159 \| NameMongkol |
| `/wallpapers/day/thursday` | คนเกิดวันพฤหัสบดีหาภาพมือถือ โทนส้มทอง ปัญญา/การเรียนรู้และเลข 659 | วอลเปเปอร์วันพฤหัสบดี พระพุทธรูป เลข 659 \| NameMongkol |

หน้ารวมยังเชื่อมไป `/wallpapers/intent/finance` ซึ่งเป็นหน้าหลักของ “วอลเปเปอร์เสริมดวงการเงิน” คง canonical ของแต่ละหน้าไว้ และไม่ย้าย keyword นี้มาเป็นหัวข้อหลักของหน้าวันเกิด

Intent ข้างต้นเป็นข้อสรุปจากรูปแบบผลค้นหาและการใช้งานหน้าเว็บ โดยตัวอย่างผลค้นหาเน้นการดูภาพ เลือกวันเกิด อ่านความหมาย และดาวน์โหลด เช่น [TrueID: วอลเปเปอร์ประจำวันเกิด](https://horoscope.trueid.net/detail/qVrNew34rPPV/) ไม่ใช่การวัดอันดับหรือปริมาณค้นหาจาก Search Console

## ภาพและเงื่อนไขใช้งาน

- ทั้งสามไฟล์เป็น WebP ขนาด 1080×1920 px ตรวจไฟล์ด้วย Sharp และเทียบภาพจริงแล้ว
- แสดงภาพตัวอย่างด้วย next/image, sizes และสัดส่วนเดิมใน HTML ก่อน JavaScript โหลด พร้อม ImageObject ที่ใช้ caption/ขนาดจากข้อมูลภาพเดียวกัน
- บทนำชี้ความหมายตามความเชื่อ ไม่รับประกันผลลัพธ์ และแยกเงื่อนไขภาพประจำวันฟรีหลังเข้าสู่ระบบออกจากภาพพิเศษที่ใช้เครดิต
- FAQ ที่มองเห็นได้และ FAQPage ใช้ข้อมูลเดียวกัน
