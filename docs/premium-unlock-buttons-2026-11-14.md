# ปุ่มปลดล็อกใกล้รายชื่อ

เพิ่มปุ่มบน overlay ของทุกการ์ดที่ยังล็อก และแผงปลดล็อกท้ายรายการก่อนส่วนอธิบายบริการ ทั้งสองตำแหน่งระบุ 15 เครดิตต่อชุดสูงสุด 20 ชื่อและหมวดอักษร ไม่สื่อว่าเป็นราคาต่อชื่อ เมื่อปลดล็อกแล้วปุ่มชุดแรกหายและคงปุ่มดูเพิ่มเดิม

ใช้ performUnlock เดียวกับปุ่มด้านบน ตรวจล็อกอิน/เครดิต และให้ผู้ใช้ยืนยันก่อนหักเสมอ เพิ่ม ref guard ตั้งแต่เริ่มโหลด dialog จนจบคำขอ รวมกรณียกเลิกและล้มเหลว ปิดปุ่มทุกตำแหน่งระหว่างทำงาน ไม่เปลี่ยน RPC ราคา สูตร หรือจำนวนชื่อที่ให้ดูฟรี และไม่เสนอปุ่มชุดแรกเมื่อทุกชื่อในหมวดอยู่ในสิทธิ์ดูฟรีแล้ว

ผลตรวจ:

- TypeScript, lint ส่วนที่แก้ และ production build ผ่าน 220 static pages
- Tests ที่เกี่ยวข้อง 3 files / 12 tests ผ่าน
- ใช้ scripts/preview-premium-unlock.cjs ทดสอบ actual ClientPage และ SweetAlert ด้วย mock auth/catalog/credit service แยกจากบัญชีจริง ไม่มีการหักเครดิตจริง
- กดปุ่มการ์ดแล้วยกเลิก จากนั้นยืนยันผ่านปุ่มท้ายรายการ: fake spend 1 ครั้ง ยอด 45 เหลือ 30 เปิด 20 ชื่อและปิดปุ่มทุกตำแหน่งระหว่างประมวลผล
- ไม่ล็อกอินเปิด dialog เดิม; เครดิต 5 แสดงเติมเครดิตและ fake spend 0; จำลองคำขอล้มเหลวทำให้ 14 การ์ดยังล็อกและปุ่มพร้อมลองใหม่
- ตรวจหน้าจริง localhost:3000 ที่ 320/390px ไม่มี overflow แผงท้ายรายการมีปุ่มเต็มความกว้างสูง 46px ปุ่มบนการ์ดเป็น interactive control ที่อยู่นอกเนื้อหา inert/aria-hidden
- ภาพหน้าจริงอยู่ที่ scratch/premium-aplus-import/premium-unlock-preview.jpg ซึ่งถูก gitignore
