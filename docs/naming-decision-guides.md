# คู่มือช่วยตัดสินใจเลือกชื่อ

เพิ่มบทความสาธารณะสองเรื่องในระบบบทความเดิม วันที่ 25 พฤศจิกายน 2026 ผู้เขียนระบุเป็นทีมงาน NameMongkol ไม่มีการสมมติผู้เชี่ยวชาญ ผู้ตรวจทาน หรือประสบการณ์ลูกค้า

| เส้นทาง | คำถามที่หน้านี้รับผิดชอบ | ขอบเขตที่ต่างจากบทความเดิม |
|---|---|---|
| `/articles/real-name-nickname-numerology` | ชื่อจริงกับชื่อเล่นต้องมีผลรวมเท่ากันไหม | แยกชื่อจริง ชื่อเล่น และชื่อเต็ม ไม่อธิบายอักษรกาลกิณีซ้ำกับ `nickname-kalakini-effect` |
| `/articles/name-meaning-vs-numerology` | เมื่อชอบความหมายแต่ผลรวมไม่ตรงเงื่อนไข จะเลือกอย่างไร | จัดลำดับเกณฑ์และทางเลือก ไม่สอนวิธีวิเคราะห์ทั้งหมดซ้ำกับ `free-name-analysis-numerology-guide` หรือเช็กลิสต์เปลี่ยนชื่อ |

ทั้งสองหน้ามีคำตอบตรงคำถาม สารบัญ คำถามเฉพาะเรื่อง และลิงก์ไปยังหมวดชื่อ หน้าความหมาย เครื่องมือวิเคราะห์ และการเปรียบเทียบชื่อ ใช้ self-canonical และ Article/FAQPage/BreadcrumbList ของ renderer เดิม Metadata ไม่เติมชื่อแบรนด์เอง เพื่อให้ template หลักแสดงแบรนด์ครั้งเดียว

## ความถูกต้องของตัวอย่าง

ตัวอย่างเป็นสถานการณ์สมมติ ไม่มีการกล่าวอ้างผลต่อชีวิตหรือแนะนำให้เปลี่ยนชื่อเพราะคะแนนเพียงข้อเดียว ตัวเลขคำนวณด้วย `calculateScore` ซึ่งเป็นสูตรเดียวกับ `/name-check`:

| ข้อความ | ผลรวม |
|---|---:|
| ธนกร | 14 |
| ธนชัย | 23 |
| ต้น | 10 |
| วัฒนกุล | 26 |
| ธนกร วัฒนกุล | 40 |
| ธนชัย วัฒนกุล | 49 |

ชื่อเหล่านี้ใช้สาธิตการเทียบข้อความ ไม่มีการยืนยันว่าความหมายหรือคำอ่านของสองชื่อเหมือนกัน ตัวเลขเป้าหมายในกรณีสมมติเป็นเงื่อนไขส่วนตัว ไม่ใช่คำแนะนำเลขที่เหมาะกับทุกคน บทความแยกความหมายและหลักฐานคำอ่านออกจากการตีความเลขศาสตร์ตามความเชื่อ

แหล่งอ้างอิงของบทความคือ `/methodology` เพื่ออธิบายการทำงานของเครื่องมือภายในเว็บไซต์ ไม่อ้างเป็นหลักฐานภายนอกที่รับรองผลลัพธ์ชีวิต ภาพหน้าปกใช้ไฟล์เดิมที่มีอยู่จริง ไม่มี asset หรือค่าใช้จ่ายสร้างภาพใหม่

## การตรวจ

`npm test -- namingDecisionGuides` ตรวจเส้นทางและการรวมในแค็ตตาล็อก ตัวเลขตัวอย่าง ลิงก์พร้อมข้อมูลตัวอย่าง สารบัญ FAQ แหล่งที่มา และไฟล์ภาพ Parent integration ควรตรวจหน้า HTML จริงทั้งสองหน้า การแสดงผู้เขียนแบบ Organization ใน JSON-LD และ sitemap หลัง build

ไม่มีการแก้ฐานข้อมูลหรือเผยแพร่บทความไปบริการภายนอก รายการใหม่ใช้ local article fallback ตามกลไกปัจจุบัน หากมีแถวฐานข้อมูลที่ใช้ slug เดียวกันในอนาคต ต้องรักษาข้อความ แหล่งอ้างอิง และข้อมูลผู้เขียนให้ตรงกันก่อนเผยแพร่
