# แก้หน้า /search แสดงเพียง 84 ชื่อ

พบว่า `.env.local` ไม่มีค่า URL และ public key ของ Supabase หลังการคืนค่า environment จาก Vercel ซึ่งค่า Sensitive ไม่สามารถดึงค่าจริงได้ เมื่อไม่มีการเชื่อมต่อ หน้า search ใช้ข้อมูลคัดสรรสำรอง 54 ชื่อรวมชื่อเสริม 30 ชื่อ จึงแสดง 84 แทนรายชื่อจริง

แก้ไข:

- ตั้งค่า URL และ publishable key จาก Supabase connector ลง `.env.local` สำหรับอ่านข้อมูลสาธารณะ ไม่แก้ private secret และไม่เพิ่มสิทธิ์ฐานข้อมูล
- ตัวอ่านรายชื่อสาธารณะ/รายละเอียดพรีเมียม/สถิติสาธารณะใช้ public key ได้เมื่อ service key เป็นสตริงว่าง แทนการเลือกค่าว่างแล้วหยุดเชื่อมต่อ
- ส่งแหล่งข้อมูล database/fallback ไปกับผลลัพธ์ และแจ้งบน /search เมื่อใช้ข้อมูลสำรอง ป้ายจำนวนไม่เรียกข้อมูลสำรองว่าจำนวนทั้งหมดในฐานข้อมูล

ตรวจข้อมูลจริงหลังแก้: REST ด้วย publishable key อ่านฐานสาธารณะได้ 7,808 แถว; API และ HTML ของ localhost:3000/search แสดง 7,838 ชื่อ (รวมชื่อเสริมในโค้ด 30 ชื่อ) พร้อมคำถอดเสียงแนะนำและป้ายรอตรวจสอบ จำนวนตรงกับ public API บนเว็บไซต์ production

ผลตรวจ: Vitest 74 files / 400 tests ผ่าน; lint เฉพาะไฟล์ที่แก้และ production build ผ่าน (220 static pages) และตรวจ HTML บนโดเมน production พบยอด 7,838 เช่นกัน
