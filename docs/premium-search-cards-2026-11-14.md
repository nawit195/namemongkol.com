# การ์ด Premium Search แบบกระชับ

ปรับตามภาพอ้างอิงให้ชื่อไทยเป็นจุดเด่น ชื่ออังกฤษกับคำอ่านอยู่บรรทัดรอง และความหมายแสดงไม่เกินสองบรรทัดก่อนกดดูเต็ม ลดกรอบซ้อน ข้อความรอข้อมูลซ้ำ และแถบตกแต่ง ใช้พื้นครีมอ่อน ข้อความสีน้ำตาลทอง ป้ายผลรวมสีเขียวเข้ม และป้ายวันเกิดแยกสีพร้อมข้อความชัดเจน

- คู่เลขย่อแสดงสี่คู่แรกพร้อมจำนวนที่เหลือ เปิดดูครบได้ในรายละเอียด
- รายละเอียดใช้ native details/summary จึงเปิดด้วยคีย์บอร์ดได้ ไม่ใช้ modal หรือเพิ่ม state/คำขอ API
- แสดงสถานะรอตรวจ/ตรวจแล้วจากข้อมูลเดิม และย้ายคำอ่านเพิ่มเติม หมวดชื่อ และคำอธิบายชื่ออังกฤษไปไว้ในรายละเอียด
- ปุ่มวิเคราะห์ส่งชื่อไป `/name-check?name=...` ตามรูปแบบเดิมและปิด prefetch
- การ์ดที่ยังล็อกไม่มี link หรือ summary ที่โฟกัสได้ เนื้อหาใช้ inert และ aria-hidden ตามสถานะ ไม่เปลี่ยนกติกาปลดล็อก ราคา หรือการหักเครดิต
- Grid ใช้พื้นที่จริงเป็นตัวกำหนดจำนวนคอลัมน์ ให้การ์ดกว้างอย่างน้อย 265px เมื่อมีพื้นที่เพียงพอ และยุบเป็นหนึ่งคอลัมน์เมื่อพื้นที่เล็กกว่า ไม่บังคับสามคอลัมน์ตามความกว้าง viewport อย่างเดียว

## ตรวจรับ

- Tests ที่เกี่ยวข้อง 3 files / 12 tests ผ่าน รวมการส่งชื่อไปวิเคราะห์และการไม่มี action ในการ์ดล็อก
- TypeScript และ lint ของส่วนที่แก้ผ่าน
- ตรวจ fixture ข้อมูลครบ/ขาด/pending/approved/locked/ชื่อยาว/แปดวันเกิด/หลายคู่เลข และหน้า `/premium-search` จริงบน localhost:3000
- Native details เปิดและย่อด้วย Enter ได้ แสดงความหมายเต็ม คำอ่านหลายแบบ และคู่เลขทั้งหมด
- 320px: การ์ดจริงกว้างประมาณ 273px, scrollWidth 305px, ปุ่ม 114×44px; 390px: การ์ดกว้าง 343px, scrollWidth 375px ไม่มีหน้า overflow
- 1280px: พื้นที่เหลือหลังเมนูและแผงอักษรแสดงสองคอลัมน์ กว้างประมาณ 284px; 1600px: สามคอลัมน์ กว้างประมาณ 291px การ์ดข้อมูลทั่วไปสูงประมาณ 326px และเพิ่มตามจำนวนบรรทัดวันเกิด/ชื่อยาว
- รองรับ reduced motion และ focus-visible ไม่มีการทดลองซื้อหรือหักเครดิตจริง
- ภาพจากหน้าจริงเก็บใน scratch/premium-aplus-import/premium-cards-preview.jpg ซึ่งไม่อยู่ใน Git

ไม่เปลี่ยนฐานข้อมูล สูตรวิเคราะห์ หรือข้อมูลชื่อ และยังไม่ Commit/Push/deploy production
